## Что вообще мы делаем

**Telegram Mini App** — это обычный сайт, который открывается **внутри Telegram** по кнопке у бота. Схема такая:

```
Вы в Telegram → бот «Rep Legends» → кнопка «Играть» → открывается наш сайт
                                                     (живёт на GitHub Pages)
```

Сначала (этапы 0–1) игре не нужен свой сервер: всё работает прямо на телефоне. Сервер понадобится на этапе 2, когда игроки начнут соревноваться друг с другом.

## Шаг 1. Установить Node.js

**Зачем:** Node.js — это программа, которая запускает наш код на компьютере и собирает игру в готовый сайт. Вместе с ней ставится **npm**: он скачивает готовые «детали» (библиотеки), например распознавание позы.

1. Откройте сайт **https://nodejs.org**.
2. Нажмите кнопку загрузки версии с пометкой **LTS**. Это версия с долгой поддержкой, самая стабильная.
3. Запустите скачанный файл и нажимайте «Next» / «Далее», ничего не меняя. Если появится галочка «Automatically install the necessary tools», её можно **не** ставить.
4. **Закройте VS Code полностью и откройте снова.** Это нужно, чтобы VS Code «увидел» новую программу.

**Проверка:** в VS Code откройте терминал (меню *Terminal → New Terminal* или клавиши `Ctrl` + `` ` ``).
**Терминал** — это окно, куда вводят команды текстом. Введите по очереди и нажимайте Enter:

```
node -v
npm -v
```

Должны появиться номера версий, например `v24.11.0` и `11.6.0`. Если пишет «не является командой», перезагрузите компьютер и попробуйте ещё раз.

## Шаг 2. Аккаунт на GitHub

**Зачем:** GitHub — это бесплатное хранилище для кода в интернете. Там же **бесплатно размещается наш сайт** (сервис GitHub Pages), причём с защищённым адресом `https://...`. Без `https` телефон не разрешит включить камеру.

1. Зайдите на **https://github.com** → **Sign up**. Зарегистрируйтесь: почта, пароль, имя пользователя.
   Имя пользователя будет частью адреса игры, например `https://ВАШЕ-ИМЯ.github.io/rep-legends/`.
2. Подтвердите почту.
3. Пришлите мне ваше **имя пользователя GitHub** (только имя, пароль не нужен!).

> ℹ️ Бесплатный сайт на GitHub Pages работает только с **публичным** хранилищем, то есть код будет виден всем. Это нормально: секретов в коде не будет. Секретный токен бота мы туда **никогда** не кладём.

### Шаг 2б. Создать хранилище `rep-legends` и включить сайт

**Зачем:** хранилище (репозиторий) — это «папка» на GitHub, куда отправляется код игры. Из неё GitHub сам собирает сайт.

1. На GitHub справа вверху нажмите **+** → **New repository**.
2. **Repository name:** `rep-legends` (именно так, маленькими буквами через дефис).
3. Выберите **Public**.
4. **Ничего больше не отмечайте** (никаких README, .gitignore, license): хранилище должно быть пустым.
5. Нажмите **Create repository**.
6. В новом хранилище откройте **Settings** (вкладка с шестерёнкой) → слева **Pages** → в поле **Source** выберите **GitHub Actions**.

Ваш адрес игры: **https://scream-byte.github.io/rep-legends/**

### Шаг 2в. Отправить код на GitHub

**Зачем:** код пока лежит только на вашем компьютере.

После шагов 2б напишите мне, и я выполню отправку (`git push`). При первой отправке **откроется окно браузера** с просьбой войти в GitHub. Войдите и нажмите **Authorize** (разрешить). Это нужно один раз: Windows запомнит вход.

## Шаг 3. Создать бота в Telegram

**Зачем:** игра открывается через бота. Бот — это «вход» в игру и, позже, тот, кто пишет итоги в группы.

1. В Telegram найдите **@BotFather** (с синей галочкой). Это официальный бот Telegram для создания ботов.
2. Нажмите **Start** и отправьте `/newbot`.
3. Введите **название** (его видят люди), например: `Rep Legends`.
4. Введите **username**. Он должен заканчиваться на `bot` и быть свободным, например `RepLegendsBot` или `RepLegendsGameBot`. Если имя занято, BotFather попросит другое.
5. BotFather пришлёт сообщение с **токеном**. Токен выглядит примерно так: `1234567890:AAH...`.

> 🔒 **Токен — это пароль от бота.** Не отправляйте его никому, в том числе мне в чат, и не вставляйте в код. Сохраните его у себя, например в менеджере паролей или в заметке, которую никто не видит. Он понадобится на этапе 2, и я покажу, куда его безопасно вписать (в файл `.env`, который не попадает на GitHub).

6. Пришлите мне **username бота** (не токен!).

## Шаг 5. Как запустить игру на компьютере *(после того как я напишу код)*

**Зачем:** так быстрее всего посмотреть изменения, ещё не выкладывая их в интернет.

В терминале VS Code, в папке проекта:
```
npm install      ← скачивает все «детали» (один раз и после обновлений)
npm run dev      ← запускает игру; в терминале появится адрес вида http://localhost:5173
```
Откройте этот адрес в браузере на компьютере. Чтобы остановить, нажмите `Ctrl` + `C` в терминале.

> На компьютере часть функций Telegram (имя, вибрация) работать не будет. Это нормально: настоящая проверка — на телефоне.

## Шаг 6. Как выложить обновление *(после этапа 0)*

**Зачем:** чтобы новая версия игры появилась у вас в Telegram на телефоне.

```
git add .
git commit -m "что изменилось"
git push
```
Через 1–2 минуты GitHub сам соберёт и обновит сайт. Проверить, что сборка прошла, можно на GitHub: ваш репозиторий → вкладка **Actions** → зелёная галочка ✅.

## Шаг 7. Как проверить на телефоне

1. Откройте своего бота в Telegram → нажмите кнопку **Играть**.
2. Если игра попросит камеру, нажмите **Разрешить**.
3. Если камера не включилась:
   - **iPhone:** Настройки → Telegram → Камера → включить. Затем полностью закройте Telegram (смахните его вверх) и откройте снова.
   - **Android:** Настройки → Приложения → Telegram → Разрешения → Камера → «Разрешить».
4. Если игра показывает старую версию, закройте окно игры и откройте снова. Если не помогло, перезапустите Telegram.

## Словарик
| Слово | Простыми словами |
|---|---|
| **Терминал** | Окно, куда вводят команды текстом вместо нажатия кнопок |
| **Node.js / npm** | Программа, которая запускает наш код / «магазин» готовых деталей для кода |
| **Репозиторий** | Папка с кодом на GitHub, где хранится вся история изменений |
| **Коммит** (`commit`) | «Сохранение» с подписью, что изменилось |
| **Пуш** (`push`) | Отправить сохранения с компьютера на GitHub |
| **Деплой** | Выложить новую версию сайта в интернет |
| **HTTPS** | Защищённый адрес сайта (с замочком). Без него камера не включится |
| **Токен** | Секретный пароль бота |
| **Сервер** | Компьютер в интернете, который работает круглосуточно и связывает игроков между собой |
| **Mini App** | Сайт, который открывается внутри Telegram |
| **MediaPipe** | Бесплатная технология Google, которая по видео находит точки тела (плечи, локти, колени) |
