## Что вообще мы делаем

**Telegram Mini App** — это обычный сайт, который открывается **внутри Telegram** по кнопке у бота. Схема такая:

```
Вы в Telegram → бот «Rep Legends» → кнопка «Играть» → открывается наш сайт
                                                     (живёт на GitHub Pages)
```

Сначала (этапы 0–1) игре не нужен свой сервер: всё работает прямо на телефоне. Сервер понадобится на этапе 2, когда игроки начнут соревноваться друг с другом.

## Шаг 1. Установить Node.js

**Зачем:** Node.js — это программа, которая запускает наш код на компьютере и собирает игру в готовый сайт. Вместе с ней ставится **npm**: он скачивает готовые «детали» (библиотеки), например распознавание позы.

1. Откройте сайт **https://nodejs.org**.
2. Нажмите кнопку загрузки версии с пометкой **LTS**. Это версия с долгой поддержкой, самая стабильная.
3. Запустите скачанный файл и нажимайте «Next» / «Далее», ничего не меняя. Если появится галочка «Automatically install the necessary tools», её можно **не** ставить.
4. **Закройте VS Code полностью и откройте снова.** Это нужно, чтобы VS Code «увидел» новую программу.

**Проверка:** в VS Code откройте терминал (меню *Terminal → New Terminal* или клавиши `Ctrl` + `` ` ``).
**Терминал** — это окно, куда вводят команды текстом. Введите по очереди и нажимайте Enter:

```
node -v
npm -v
```

Должны появиться номера версий, например `v24.11.0` и `11.6.0`. Если пишет «не является командой», перезагрузите компьютер и попробуйте ещё раз.

## Шаг 2. Аккаунт на GitHub

**Зачем:** GitHub — это бесплатное хранилище для кода в интернете. Там же **бесплатно размещается наш сайт** (сервис GitHub Pages), причём с защищённым адресом `https://...`. Без `https` телефон не разрешит включить камеру.

1. Зайдите на **https://github.com** → **Sign up**. Зарегистрируйтесь: почта, пароль, имя пользователя.
   Имя пользователя будет частью адреса игры, например `https://ВАШЕ-ИМЯ.github.io/rep-legends/`.
2. Подтвердите почту.
3. Пришлите мне ваше **имя пользователя GitHub** (только имя, пароль не нужен!).

> ℹ️ Бесплатный сайт на GitHub Pages работает только с **публичным** хранилищем, то есть код будет виден всем. Это нормально: секретов в коде не будет. Секретный токен бота мы туда **никогда** не кладём.

### Шаг 2б. Создать хранилище `rep-legends` и включить сайт

**Зачем:** хранилище (репозиторий) — это «папка» на GitHub, куда отправляется код игры. Из неё GitHub сам собирает сайт.

1. На GitHub справа вверху нажмите **+** → **New repository**.
2. **Repository name:** `rep-legends` (именно так, маленькими буквами через дефис).
3. Выберите **Public**.
4. **Ничего больше не отмечайте** (никаких README, .gitignore, license): хранилище должно быть пустым.
5. Нажмите **Create repository**.
6. В новом хранилище откройте **Settings** (вкладка с шестерёнкой) → слева **Pages** → в поле **Source** выберите **GitHub Actions**.

Ваш адрес игры: **https://scream-byte.github.io/rep-legends/**

### Шаг 2в. Отправить код на GitHub

**Зачем:** код пока лежит только на вашем компьютере.

После шагов 2б напишите мне, и я выполню отправку (`git push`). При первой отправке **откроется окно браузера** с просьбой войти в GitHub. Войдите и нажмите **Authorize** (разрешить). Это нужно один раз: Windows запомнит вход.

## Шаг 3. Создать бота в Telegram

**Зачем:** игра открывается через бота. Бот — это «вход» в игру и, позже, тот, кто пишет итоги в группы.

1. В Telegram найдите **@BotFather** (с синей галочкой). Это официальный бот Telegram для создания ботов.
2. Нажмите **Start** и отправьте `/newbot`.
3. Введите **название** (его видят люди), например: `Rep Legends`.
4. Введите **username**. Он должен заканчиваться на `bot` и быть свободным, например `RepLegendsBot` или `RepLegendsGameBot`. Если имя занято, BotFather попросит другое.
5. BotFather пришлёт сообщение с **токеном**. Токен выглядит примерно так: `1234567890:AAH...`.

> 🔒 **Токен — это пароль от бота.** Не отправляйте его никому, в том числе мне в чат, и не вставляйте в код. Сохраните его у себя, например в менеджере паролей или в заметке, которую никто не видит. Он понадобится на этапе 2, и я покажу, куда его безопасно вписать (в файл `.env`, который не попадает на GitHub).

6. Пришлите мне **username бота** (не токен!).

## Шаг 5. Как запустить игру на компьютере *(после того как я напишу код)*

**Зачем:** так быстрее всего посмотреть изменения, ещё не выкладывая их в интернет.

В терминале VS Code, в папке проекта:
```
npm install      ← скачивает все «детали» (один раз и после обновлений)
npm run dev      ← запускает игру; в терминале появится адрес вида http://localhost:5173
```
Откройте этот адрес в браузере на компьютере. Чтобы остановить, нажмите `Ctrl` + `C` в терминале.

> На компьютере часть функций Telegram (имя, вибрация) работать не будет. Это нормально: настоящая проверка — на телефоне.

## Шаг 7. Как проверить на телефоне

1. Откройте своего бота в Telegram → нажмите кнопку **Играть**.
2. Если игра попросит камеру, нажмите **Разрешить**.
3. Если камера не включилась:
   - **iPhone:** Настройки → Telegram → Камера → включить. Затем полностью закройте Telegram (смахните его вверх) и откройте снова.
   - **Android:** Настройки → Приложения → Telegram → Разрешения → Камера → «Разрешить».
4. Если игра показывает старую версию, закройте окно игры и откройте снова. Если не помогло, перезапустите Telegram.

## Чек-листы проверки по этапам

### Этап 0 — «пустое» приложение ✅
- [x] Бот → «Играть» → открылась игра, видно ваше имя, экран не нужно прокручивать.
- [x] Новый главный экран, герой-яблоко, значок уровня.

### Настройки и музыка
1. Закройте окно игры и откройте снова через **Играть**.
2. Музыка должна заиграть **сразу**. Если телефон запрещает звук без касания, справа под кнопкой «Статы» будет мигать круглая жёлтая кнопка **🔊** — коснитесь её (или любого места экрана), и музыка заиграет.
   - На iPhone проверьте, что **выключен беззвучный режим** (переключатель сбоку телефона), иначе звука не будет.
3. Нажмите **⚙️ шестерню** в правом верхнем углу (это настройки):
   - [ ] **Язык** переключается, все надписи меняются.
   - [ ] **Общая громкость**, **Музыка**, **Эффекты** — ползунки меняют громкость (после «Эффектов» звучит «удар»).
   - [ ] **Яркость** делает картинку игры светлее или темнее.
   - [ ] **Меньше анимаций** останавливает вращение лучей и покачивание героя.
   - [ ] **Вибрация** — при включении телефон коротко вибрирует.
   - [ ] Закройте и снова откройте игру: настройки **сохранились**.
4. - [ ] На тренировке музыка **затихает**, но есть звуки: отсчёт 3-2-1, «удар» на каждое отжимание, фанфары в конце.

### Этап 3 — приседания
1. Полностью закройте Telegram и откройте игру → **«В бой!»** → **Приседания** (у карточки больше нет замочка).
2. Прочитайте правила, поставьте телефон **вертикально на пол в 2–3 м** и встаньте **боком** к нему. В кадре — всё тело, включая стопы.
3. Нажмите **«Включить камеру»**, встаньте прямо → плашка станет зелёной → **3-2-1**.
   - [ ] Если встать **лицом** к телефону, игра попросит «Повернись боком».
4. - [ ] **15–20 обычных приседаний** (бёдра примерно параллельны полу) → игра насчитала почти все.
   - [ ] **Полуприсед** (чуть-чуть присели) → не засчитано, «Чуть ниже!».
   - [ ] Сильно **наклонились вперёд** («клевок») → «Спину ровнее, грудь вперёд!».
   - [ ] Быстрые **пружинки** внизу → «Слишком быстро! Плавнее».
5. **Стоп** → результат: «+N опыта · Выносливость». В окне **«Статы»** Выносливость больше не «скоро», у неё уровень и полоска опыта.
6. Если счёт ошибается — включите **🐞 Отладку** и пришлите скриншот (строка вида `left · knee 95° · lean 35°`).

### Статы и сохранения
1. Закройте окно игры и откройте снова.
   - [ ] **«В бой!» → Арены**: на карточке подтягиваний снова виден ваш **старый рекорд** (он перенесён в «Средний»).
2. Нажмите **«Статы»** на главном экране.
   - [ ] У **Атаки** и **Силы** есть уровень и полоска опыта, у Выносливости и Защиты — «Скоро».
   - [ ] Внизу надпись **«☁️ Прогресс сохранён в облаке Telegram»**.
3. Сделайте подход отжиманий или подтягиваний.
   - [ ] На экране результата: **«+N опыта · Атака/Сила»**, а при новом уровне — «⬆ Атака: уровень 2!».
   - [ ] Внизу результата: «☁️ Прогресс сохранён в облаке Telegram».
   - [ ] На главном экране щит героя и полоска опыта сверху выросли.
4. **Проверка надёжности (по желанию):** откройте игру на **втором телефоне** с тем же аккаунтом Telegram — уровни и рекорды должны появиться там тоже.

**Сколько даёт опыта** (можно поменять — напишите мне):
- 1 отжимание = 1 опыт **Атаки**;
- 1 подтягивание = 2 / 3 / 4 опыта **Силы** (лёгкий / средний / тяжёлый);
- 1 присед = 1 опыт **Выносливости**;
- новый уровень стата: 10, потом 15, 20, 25… опыта; уровень игрока (щит сверху) — как раньше: 50, потом 75, 100… (от всего опыта вместе);
- за старые рекорды (до появления опыта) опыт начисляется один раз автоматически.

**Как понять, что у вас свежая версия:** ⚙️ → «Технические данные» → «Версия игры» (дата и время сборки). Если дата старая — полностью закройте Telegram (смахните из списка приложений) и откройте снова.

### Сложности подтягиваний
1. **«В бой!» → Подтягивания** → открылся экран **«Выбери сложность»**.
   - [ ] Три карточки: **Лёгкий** ★☆☆, **Средний** ★★☆, **Тяжёлый** ★★★, у каждой описание правил.
   - [ ] Внизу переключатель **«Подтягиваюсь с резинкой»**. На тяжёлом он выключен и не нажимается.
2. **Средний**, без резинки: сделайте 2 чистых подтягивания и 2 **с раскачкой** (ноги/корпус качаются, колени к груди).
   - [ ] Чистые = по 1 очку, с раскачкой = по ½ и надпись «Раскачка — ½ очка». Итого должно быть **3**.
   - [ ] В результате видно: «Чистых: 2», «С раскачкой: 2».
3. **Тяжёлый**: подтягивание с раскачкой → «Без раскачки! Не засчитано», 0 очков.
4. **Лёгкий**: с раскачкой → 1 очко, руки внизу можно выпрямлять не до конца.
5. Если раскачку игра **не замечает** или, наоборот, ругается на чистые подтягивания — включите **🐞 Отладку** и пришлите скриншот: во **второй строке** `swing: pitch … · hips … · sway …` видно, что игра «думает» о раскачке.

### Этап 2 — арены и подтягивания
**Подготовка**
1. Закройте окно игры и откройте снова через **Играть**.
2. Нажмите **«В бой!»** (или «Арены»).
   - [ ] Открылся экран **«Арены»**: Отжимания (Атака), Подтягивания (Сила), а Приседания и Пресс — с замочком «Скоро». На карточках виден рекорд.
3. Нажмите **Подтягивания** → появится картинка «Как поставить телефон».
4. Поставьте телефон **на пол в 2–3 м от турника**, экраном к себе, и **прислоните** его (к стене, книге, бутылке), чтобы камера смотрела немного вверх на турник.
5. Нажмите **«Включить камеру»**, встаньте под турник — **лицом или спиной** к телефону, как удобнее.
   - [ ] В кадре видно **руки на перекладине и плечи**. Голова и ноги не обязательны. *(Если рук не видно — отодвиньте телефон дальше или наклоните сильнее.)*

**Подсчёт**
6. Повисните на прямых руках.
   - [ ] Плашка стала зелёной, и **подсчёт начался сам** (без 3-2-1).
7. - [ ] **10 честных подтягиваний** (подбородок до перекладины, внизу руки прямые) → игра насчитала **9–10**.
   - [ ] Подтянулись **не до конца** → не засчитано, подсказка «Подбородок выше перекладины!».
   - [ ] Подтянулись, **не выпрямив руки внизу** → не засчитано, подсказка «Выпрямляй руки внизу!».
8. Спрыгните с турника.
   - [ ] Появилась надпись «Подход завершится через 3… 2… 1…», и открылся **результат** с рекордом.

**Отладка**
9. До начала (во время калибровки) нажмите **🐞 Отладка**, повисните и сделайте **скриншот**. Строка внизу вида `elbow 165° · bar -1.20 · back · hang` поможет мне точно подстроить счёт под вас (`face` — камера видит лицо, `back` — спину). Хорошо бы прислать два скриншота: в нижней точке (руки прямые) и в верхней (подбородок у перекладины).

**Если не получается** поставить телефон так, чтобы всё было видно, или счёт сильно ошибается — напишите, придумаем другой способ (например, считать по датчику движения телефона в кармане).

## Словарик
